# To-Do List App

A lightweight, responsive Task Manager built with **Vanilla JavaScript**. This application allows users to organize their daily tasks with a clean, mobile-friendly interface and persistent state management.

## 🚀 Live Demo
https://btsholicmeee0613.netlify.app

## ✨ Features
* **Add Tasks:** Quickly add new items to your list.
* **Done/Undone:** Toggle task completion status with a single click.
* **Delete:** Remove tasks you no longer need.
* **Responsive UI:** Fully optimized for Mobile, Tablet, and Desktop screens.
* **Visual Cues:** Strikethrough text and color changes for completed tasks.

## 🛠️ Technologies Used
* **HTML5:** Semantic elements for accessibility.
* **CSS3:** Flexbox/Grid for responsiveness and custom styling.
* **JavaScript (ES6):** DOM manipulation and event handling for task logic.
